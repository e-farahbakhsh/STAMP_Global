BHP STELLAR Project
STELLAR Phase 4A Model

Global Plate Motion Model for 2 Ga to present, with:
* New model for Western North America for 410 to 0 Ma
* Model extended from 1 to 1.8 Ga using Cao et al. (2024), and extended to 2 Ga by Sabin Zahirovic 
* Paleomagnetic reference frame is 0 Anchored Plate ID
* Optimised mantle reference frame is 702702 Anchored Plate ID
* Age-grid raster is in paleomag netcdf grids, but attached to the global clipping polygon it can be easily recast into any other reference frame or fixed plate 
* Rigid plate motions and plate boundaries
* Optimised deformation in extensional settings for 240 to 0 Ma


To load the model in GPlates do the following:

1.  Open GPlates 2.5 or newer 
2.  Pull down the GPlates File menu and select the operation Open Project
3A. Click the STELLAR-Phase4A.gproj file, and click Open. This will take less than 1 minute to load.
3B. To load the files with the deforming model points, select the STELLAR-Phase4A-ClippedDefPoints.gproj file, and click Open. This will take 5 to 10 minutes to load, depending on your machine.
3C. To load the files with the seafloor age-grid from 2000 to 0 Ma, open the STELLAR-Phase4A-AgeGrid.gproj project file. 

Alternatively, drag and drop the GPROJ file onto the globe.
